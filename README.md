## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Chandra142/Portfolio.git
cd Portfolio
```

### Run locally

```bash
node serve-local.js
```

👉 Open in browser:
`http://127.0.0.1:8000`
